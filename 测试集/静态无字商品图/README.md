## 使用顺序

先读该例的前三份文字，**只上传杂乱伪实拍开场**；根据小间需要补细节或另一角度。清晰整体照用于必要的诊断对照，不默认先上传全部清晰图。记录补图前后表现、纠正、人工帮助和实际使用素材。

重点验收商品还原、作品表达、布景空间感，以及同机位／换机位／同房间换位置的环境一致性；相似配色不等于同一房间。

复用例的目标环境视觉基准来自前置任务真实产品输出，当前没有也不预造。实际产品不支持分支或保存视觉参考时如实记能力缺口，不靠绕过产品伪造通过。每家店铺的数据隔离。
