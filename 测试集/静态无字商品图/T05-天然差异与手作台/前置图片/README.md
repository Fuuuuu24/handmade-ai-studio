# T05 前置图片

商品：P05。四张图片均为 AI 合成，用于输入，不是产品生成结果。

| 文件 | 使用顺序与用途 |
| --- | --- |
| 04-杂乱伪实拍.png | 主任务首先只上传这一张，检查复杂背景中的主体识别和处理 |
| 03-关键细节.png | 小间需要核对具体结构／材质时补充，记录提出补图的原因 |
| 02-另一角度.png | 小间需要侧面信息或换机位时补充，记录具体需求 |
| 01-整体照.png | 清晰基准；其他输入仍无法判断时用作诊断对照，不默认开场提供 |

补图顺序根据小间实际请求选择，不机械依次上传。发现明确判断错误仍未请求补图时，先记录错误，再模拟用户指出问题并提供相关照片。不能把所有清晰图开场一并上传，掩盖复杂输入的区分。

若原生界面必须先确认素材才能分析，按真实流程操作并记录限制。主体身份、数量与主要结构已逐图目视检查；微小纹理、折射和透视不保证逐像素相同，精确尺寸来源于模拟商家设定。

完整来源、提示词及哈希见 ../../图片生成清单.json。目标环境基准需在产品测试中实际生成、确认、保存，本目录不预造环境答案图。
