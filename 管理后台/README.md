# 一间 · 管理后台

用于查看系统提示词、独立维护模型列表。只从手作工作台读取配置，不写回主产品。

v1.1（2026-11-01 已实现，未部署）：「供应商与凭据」页在这里统一管理 AIHubMix key 和协作者用的团队口令，加密写进服务器上的凭据文件，由主产品读取；后台与主产品同机部署在香港服务器，经 SSH 隧道使用。见 [PRD](prd/PRD.md) v1.1 和主产品 `docs/tech-design.md` 第 12 节。

## 启动独立管理版本

需要 Node.js 24；没有依赖需要安装。

```sh
cd /Users/ice_2102/Desktop/handmade-ai-studio/管理后台/正式代码
npm start
```

打开 [独立管理后台](http://127.0.0.1:4177)。默认只接受这个本机地址，不接受局域网访问。若端口占用，可用 `ADMIN_PORT=4180 npm start`，再打开对应的 `127.0.0.1` 地址。一个数据目录只运行一个服务进程。

首次打开自动读取主产品的 3 个配置文件。后台修改保存在 `正式代码/data/state.json`，重启保留，不入 Git。界面里“主产品原文”指上次同步快照；主产品有变化后去“来源同步”检查并确认更新。后台修改过的内容保留，“差异对比”可看到与最新来源的区别。

“启用”“默认模型”都只对后台配置有效。没有发布、写回、连通性测试或网关调用功能。

「供应商与凭据」页要两个环境变量，和主产品用同一份：`CREDENTIALS_PATH`（凭据文件的绝对路径，放在仓库以外）和 `CREDENTIALS_MASTER_KEY`（32 字节随机数的 base64，单独备份）。没设置时页面显示「未设置」，不能保存。主产品的地址默认是 `http://127.0.0.1:3000`，不一样时用 `PRODUCT_INTERNAL_URL` 指定，页面靠它显示「主产品当前读取」。key 只写不读回，页面只显示尾号；团队口令只在生成时显示一次。

部署到服务器后，用 `npm run remote` 经 SSH 隧道打开：先把服务器地址写进本目录的 `.ssh-host`（如 `用户名@服务器`，不入库）或设 `ADMIN_SSH_HOST`，再打开 `http://127.0.0.1:4177`。隧道两端端口要相同，本机不要同时开本地后台。可导出完整 JSON，包含后台版本和修改记录；当前不提供导入。

## 启动交互原型

```sh
cd /Users/ice_2102/Desktop/handmade-ai-studio/管理后台/原型
npm start
```

打开 [交互原型](http://127.0.0.1:4176)。原型通过 HTTP 加载 `seed.json`，不能双击 HTML 代替本地服务。原型的编辑只存当前浏览器 localStorage，与正式版数据完全独立；来源同步仅为演示。如需重新生成原型静态快照，运行 `npm run snapshot`（只读取主产品，覆盖原型自己的 `seed.json`，不清除浏览器已保存的演示编辑）。

## 日常检查

```sh
cd /Users/ice_2102/Desktop/handmade-ai-studio/管理后台/正式代码
npm run check
npm test
```

测试使用临时后台数据，不调用模型。Node 读取主项目 TypeScript 时可能显示 `MODULE_TYPELESS_PACKAGE_JSON` 警告：来源模块会重新按 ES module 解析，不影响当前读取；不应为消除该警告擅自修改主产品的 package.json。

## 当前限制

- 只有本地单用户管理；无账号、部署、云同步。
- 价格与能力来自主项目配置，未重新联网核验，也未验证实际模型效果。
- 不读取浏览器里的真实作品、聊天或逐件生成提示词。
- 来源 TypeScript 结构变化导致读取失败时会报错，保留已有后台数据，不用默认值冒充同步成功。
- 恢复历史版本会保存当前已保存版本；未保存的编辑需先保存，或在确认提示后放弃。
- 读取 3 个配置模块前后没有对主产品加文件锁；请在主产品代码保存完成后再同步。
