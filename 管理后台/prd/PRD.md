# 一间管理后台 PRD

版本：v1.0，2026-11-01。范围由用户确认：先交互原型，再独立管理版本；允许从主产品单向同步，禁止写回主产品。

## 目标与边界

给项目维护者直观查看和整理小间的系统提示词、白底提示词和模型列表。在一个独立本地网站里完成修改、留版本和导出，避免直接翻源码。参考 CBI Admin 的侧栏、内容预览、列表筛选与详情编辑，不搬入账号运营、采购和商业化等无关功能。

所有后台编辑仅影响后台。主产品不会读取这里的配置；“默认模型”“启用”都明确是后台配置。首版不调模型、不测试连通性、不读取密钥、不产生模型费用、不部署。

## 目录与阶段

- `prd/`：需求、技术方案、验收记录。
- `原型/`：可独立运行的交互原型，使用主产品真实配置的静态快照，修改保存在原型浏览器本地。同步只演示交互，不能伪称实时读取。
- `正式代码/`：独立本地网站，真实只读同步主产品文件；后台配置保存在该目录自己的数据文件。

执行顺序：PRD 与技术写法 → 完整交互原型 → 独立正式版本 → 功能与浏览器验证。每阶段报告，不重复询问已确认范围。正式版与原型都保留。

## 页面

### 系统提示词

以“提示词列表 + 内容编辑器”为主，默认打开小间系统规则。提供搜索、原文/后台草稿切换、按 Markdown 标题跳转、字符数、来源文件、修改状态、保存及历史版本。保存前可查看差异；历史版本可恢复为新草稿版本，不覆盖历史。

固定项为小间系统规则与白底提示词模板。白底模板以 `{{keep}}` 展示可选保真要求，预览可输入该变量；小间提示词附加 `{{state}}` 展示请求时的作品状态，不编造真实商家数据。说明单件作品的最终场景生图提示词由小间动态生成，不属于固定系统提示词。

### 模型管理

搜索模型显示名/API ID，按对话/生图、启用状态筛选。表格展示厂商、用途、能力、后台状态、默认标记和来源状态。支持新增、编辑、启停和分别设置对话/生图默认模型。

对话模型字段：API ID、显示名、厂商、看图能力、推理强度、输入与输出价格（美元/百万 token）。生图字段：API ID、显示名、厂商、单张与单参考图价格、参考图上限、比例或尺寸策略、各比例尺寸、输出格式、额外参数 JSON。价格必须明确是估价。新增 ID 不得重复，不允许负价和非法参数。默认模型必须启用；必须先切换默认再停用该模型。原始配置只读。

### 来源同步

展示允许读取的源文件、内容摘要和同步时间。用户先预览同步差异，再执行同步。源文件变化时更新只读基准；对未编辑项跟随源文件，对后台修改过的项保留草稿并标出分歧。主产品删除的项保留为“来源已移除”，新增项进入列表。重新同步不能静默覆盖后台草稿。后台默认模型单独维护，源默认变化仅在后台默认未改动时跟随。

### 修改记录与导出

按时间记录后台保存、模型变更、同步与版本恢复。支持查看提示词版本、恢复成新版本，导出完整 JSON（含版本、来源和后台配置）。无发布/写回入口。

## 验收标准

1. 默认数据来自手作工作台真实源码，首次载入有 2 个提示词、2 个对话模型、4 个生图模型；若源码后续变化，以真实同步结果为准。
2. 后台修改重启后保留；显示原始配置与后台配置差异。
3. 提示词草稿、版本恢复和模型新增/编辑/启停/默认设置可走通；非法数据返回具体错误，不能假保存。
4. 单向同步预览明确增删改，执行后保留冲突草稿。版本冲突拒绝保存并请用户刷新。
5. 浏览器可完成关键操作，支持键盘焦点、明确表单标签、空结果和失败反馈，提供截图证据。
6. 测试不调用真实模型、不读取环境密钥、不改主产品；服务器只监听本机。

## 已知限制

独立后台配置不是主产品的生效配置；目前没有账号、远端访问和多人协作。不管理用户作品及逐件生成提示词。源码结构不能被识别或导入失败时明确报错，禁止拿旧值冒充成功同步。
