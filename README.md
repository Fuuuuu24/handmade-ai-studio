# 一间 · 手作影像工作台

理解手作故事，帮助独立手作商家制作真实、有个人风格的电商商品主图。

> **项目阶段：产品需求评审与本地交互原型。** `原型-v2/` 已能走通「资产 → 信息 → 共创 → 方案 → 出图」的完整流程，但助手为规则引导、白底和候选图均为本地演示图，**尚未接入真实 AI 对话、白底处理与图像生成**。当前仓库不能作为完整生图产品使用。

## 产品方向

- 作品列表与单件工作区，长期保存商品资产、共创记录、方案和结果版本。
- 先深入共创；用户不知道如何表达时，通过推荐选卡形成作品总结。
- 商品真实性与风格分别验收，两项均通过才算完成。
- 单件作品、多张参考图；静物展示优先，真人佩戴后续验证。
- 主图比例可选 `1:1`、`3:4`、`9:16`；每次一种比例、两张候选图。
- 审核摄影方案和提示词后生成，保留版本并支持对比。
- 保存并复用摄影布景，逐步积累店铺视觉风格。

以上为已确认需求，不代表全部已经实现。完整范围与待决策项见 [PRD](docs/PRD.md)。

## 本地运行

原型位于 `原型/`，正式代码将放在 `正式代码/`（尚未开始）。需要 Node.js 18 或以上，当前没有第三方依赖，无需先运行 `npm install`。

```sh
cd 原型
npm start
```

默认访问 `http://127.0.0.1:4173`，仅监听本机回环地址。可通过 `PORT` 环境变量调整端口。

目前只能查看页面骨架：`index.html` 引用的 `app.js` 尚未实现，交互入口不会工作。样式含外部字体请求，离线时使用系统字体回退。

### 原型 v2（推荐查看）

`原型-v2/` 按 PRD v0.2 重做，视觉为纯白简约风格（参考 Lovart 取色与字号），页面结构沿用旧原型。无第三方依赖。

```sh
cd 原型-v2
npm start
```

默认访问 `http://127.0.0.1:4174`。首页可「载入示例作品」直接体验；数据只存在当前浏览器。演示内容（白底、候选图、助手回复）均有明确标注，不代表真实 AI 效果。

## 验证与已知限制

```sh
cd 原型
node --check server.mjs
npm run check
```

`原型-v2/` 下运行 `npm run check` 检查全部脚本语法。v2 已在 Chrome 中实测主流程、窄屏布局、服务访问限制和输入转义；未做跨浏览器与真实用户测试。

旧 `原型/`：`node --check server.mjs` 可检查现有服务脚本语法。当前 `npm run check` 因缺少 `app.js` 不能通过；补齐脚本后应运行完整检查并验证浏览器流程。

仓库的 `Source checks` 工作流检查已有脚本语法，并在业务脚本缺失时明确提示；其通过不代表产品流程、模型效果或真实性已验证。

## 如何一起维护

1. 提出问题或功能建议，请创建 Issue；报告问题时不要公开密钥、用户照片或私人聊天。
2. 准备改动时，Fork 仓库，在自己的分支上开发。
3. 阅读 `agents.md` 与 PRD，将 Pull Request 提交到本仓库 `main`。
4. 由仓库所有者审核并决定是否合并。提出 Issue 或 PR 不会自动获得仓库写入或合并权限。

首批真实用户试用由项目发起人协调。欢迎围绕工作台、需求流程、可访问性和真实图像能力提出建议。
